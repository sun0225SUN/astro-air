사용자 정의 페이지는 소개, 링크, 판권 안내처럼 블로그 글에 속하지 않는 콘텐츠에 적합합니다. 별도의 콘텐츠 컬렉션을 사용하며 하나의 동적 경로에서 생성됩니다.

<Callout title="어디에 두나요">
  `.md` 또는 `.mdx` 파일을 `src/content/pages/<언어>/`에 저장합니다. 언어 디렉터리를 기준으로 한 상대 경로가 URL이 됩니다. `ko/about.mdx`는 `/ko/about`, `ko/projects/index.md`는 `/ko/projects/index`에 해당합니다.
</Callout>

각 페이지에는 `title`과 `description`이 필요합니다. 파일을 추가하면 접근 가능한 페이지가 생성되지만 상단 탐색 메뉴에 자동으로 추가되지는 않습니다. `src/config.ts`의 `nav` 배열에 페이지 경로를 추가해야 하며, 배열 안의 위치가 탐색 순서를 결정합니다.

`draft: true`를 지정하면 개발 환경에서는 미리 볼 수 있지만 프로덕션 빌드에서는 제외됩니다. 다른 언어판을 제공하려면 해당 언어 디렉터리에 같은 상대 경로로 파일을 만드세요. 실제 파일이 있는 언어에만 해당 페이지가 생성됩니다.
