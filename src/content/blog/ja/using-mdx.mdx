MDX はコンポーネントを置ける Markdown です。`astro.config.mjs` で `@astrojs/mdx` を有効にすると、ブログコレクションは `.md` と `.mdx` の両方を読みます。

<Callout title="コンポーネントは静的">
  MDX 内のコンポーネントはビルド時に HTML になります。ブラウザで動かすときだけ client ディレクティブを付けます。
</Callout>

## 記事を書く

1. `src/content/blog/<言語>` にファイルを追加する。
2. `title`、`description`、`pubDate` を書く。
3. Markdown 以上のものが要るときだけコンポーネントを import する。
